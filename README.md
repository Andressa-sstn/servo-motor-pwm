# servo-motor-pwm

# 🚀 Controle de Servomotor com Raspberry Pi Pico (PWM)

Este projeto implementa o controle de um **servomotor** utilizando **PWM (Pulse Width Modulation)** no **Raspberry Pi Pico W**, conforme especificações da atividade. O código foi desenvolvido em **C** utilizando o **Pico SDK** e testado no simulador **Wokwi**.

## 📌 Funcionalidades Implementadas
✅ Configuração do **PWM na GPIO 22** com frequência de **50Hz (20ms de período)**.  
✅ Definição dos **ângulos do servo (0°, 90°, 180°)** com ciclos ativos precisos.  
✅ Implementação de **movimentação suave** do servo de **0° a 180°** e vice-versa.  
✅ **Integração com LED RGB** na GPIO 12 para análise do comportamento do PWM.  
✅ Código organizado e estruturado para compilação no **VS Code com CMake**.
